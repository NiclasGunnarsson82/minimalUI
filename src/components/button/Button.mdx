# Button
 
Buttons are elements that signify and execute actions in the user-interface. They can be used in places like:

- Forms
- Dialogs and modals
- Page headers and sections
- Cards and lists





## Implement a button

#### Import component
<Source
  language="tsx"
  code={
    `import { Button } from './Button'`}
/>

#### Basic configuration
<Source
  language="tsx"
  code={
    `
    <Button 
      label="Save" 
      style="primary"
      state="enabled"/>`}
/>

## Optional properties


### minWidth

Prevents the button from shrinking below a certain width.

- **Only applies when fullWidth is `false`.**





### fullWidth

Makes the button span the full width of its parent container.

- **Accepts a boolean (`true` or `false`).**




### stateLabels

Customises the button text for success, error and loading states. Available states depend on the selected style.

## Interactions & refs


### onClick
Passes an event handler to the onClick prop. Provides access to the event object.

<Source
  language="tsx"
  code={
    `
    import type { MouseEvent } from "react"

    const handleClick = (event: MouseEvent<HTMLButtonElement>): void => {
        event.preventDefault()
        console.log("clicked")
    }

    <Button
        label="Save"
        style="primary"
        state="enabled"
        onClick={handleClick}
    />`}
/>


### ref
Passes a ref to the component to get a direct reference to the underlying HTMLButtonElement.

<Source
  language="tsx"
  code={
    `
    import { useRef } from "react"

    const buttonRef = useRef<HTMLButtonElement>(null)

    <Button 
      label="Save" 
      style="primary"
      state="enabled"
      ref={buttonRef}
    />`}
/>
