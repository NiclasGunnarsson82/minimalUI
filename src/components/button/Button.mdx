# Button
 
Buttons are elements that signify and execute actions in the user-interface. They can be used in places like:

- Forms
- Dialogs and modals
- Page headers and sections
- Cards and lists





## Implement a Button

#### Import component
<Source
  language="tsx"
  code={
    `import { Button } from './Button'`}
/>

#### Basic configuration
<Source
  language="tsx"
  code={
    `
    <Button 
      label="Save" 
      style="primary"
      state="enabled"/>`}
/>

## Required properties

### label

The button text.



### style

Provides visual hierarchy, helping users understand the importance and relationship between actions. 

- **primary**: use for main goals or actions.

- **secondary**: use for alternative or supporting actions.

- **tertiary**: use for low emphasis actions.

## Optional properties


### minWidth

Makes sure the button doesn't shrink below a certain width.

- **Accepts a number representing the minimum width in pixels.**
- **Only applies when fullWidth is `false`.**





### fullWidth

Makes the button span the full width of its parent container. Defaults to `false`.

- **Accepts a boolean (`true` or `false`).**




### stateLabels

Customises the HTMLButtonElement button text for success, error and loading states. Available states depend on the selected style:

- **loading:** available for primary only. 

- **success:** available for primary only.

- **error:** available for primary only.

#### Configuration
<Source
  language="tsx"
  code={
    `    
    <Button
      label="Save"
      state="enabled"
      style="primary"
      stateLabels={
          loading: "Saving",
          success: "Saved",
          error: "Server error"
      }
      />
    `}
/>

## Interactions & Refs


### onClick
Pass an event handler to the onClick prop. Provides access to the event object.

<Source
  language="tsx"
  code={
    `
    import type { MouseEvent } from "react"

    const handleClick = (event: MouseEvent<HTMLButtonElement>): void => {
        event.preventDefault()
        console.log("clicked")
    }

    <Button
        label="Save"
        style="primary"
        state="enabled"
        onClick={handleClick}
    />`}
/>


### ref
Pass a ref to the component to get a direct reference to the underlying HTMLButtonElement.

<Source
  language="tsx"
  code={
    `
    import { useRef } from "react"

    const buttonRef = useRef<HTMLButtonElement>(null)

    <Button 
      label="Save" 
      style="primary"
      state="enabled"
      ref={buttonRef}
    />`}
/>
