# Checkbox

Checkboxes allow users to select one, none, or several options in the user-interface. They can be used:

- Independently 
- In checkbox lists
 
## Implementation

#### Import component
<Source
  language="tsx"
  code={
    `import { Checkbox } from '${packageName}'`}
/>

#### Checkbox object
<Source
  language="tsx"
  code={
    `import { Checkbox } from '${packageName}'
    import type { CheckboxType } from '${typePackageName}'

    const checkboxItem: CheckboxType = {
        name: "terms_conditions",
        label: "Accept terms and conditions"
    }
`}
/>

#### Basic configuration
<Source
  language="tsx"
  code={
    `import { Checkbox } from '${packageName}'
    import type { CheckboxType } from '${typePackageName}'

    const checkboxItem: CheckboxType = {
        name: "terms_conditions",
        label: "Accept terms and conditions"
    }

    <Checkbox 
      state="default"
      checkbox={checkboxItem}/>
`}
/>
